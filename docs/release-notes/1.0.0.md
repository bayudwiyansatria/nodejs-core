# Release Notes

## Version 1.0.0

### 📅 Release Date

May 8, 2026

### 📖 Overview

Initial release of `@bayudwiyansatria/templates-project-nodejs`, a reusable Node.js library template repository. This
version focuses on project scaffolding, build/test tooling, and documentation standards for creating publishable
libraries.

### 🚀 Features

- **Template-first structure**: Clean baseline to bootstrap new Node.js libraries
- **TypeScript support**: Ready-to-use TypeScript configuration files
- **Build pipeline**: Rollup setup for library packaging
- **Test pipeline**: Jest configuration for unit testing
- **Code quality tooling**: ESLint and Prettier configuration
- **API docs generation**: TypeDoc integration
- **Repository governance docs**: Contributing, security, support, and code of conduct files

### 🔧 Enhancements

- **Consistent docs layout**: `docs/README.md`, `docs/SUMMARY.md`, release notes, and dated change logs
- **Standardized scripts**: Build, lint, test, and docs scripts centralized in `package.json`
- **Release tracking baseline**: Initial changelog and release note structure ready for future versions

### 🔐 Security

- Security reporting policy included in [SECURITY.md](../../SECURITY.md)
- Repository governance files included for safer collaboration workflows

### 🐛 Known Issues

- Build and tooling dependencies include Rollup, TypeScript, ESLint, Jest, and TypeDoc
