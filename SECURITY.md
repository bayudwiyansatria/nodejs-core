# Security Policy

## Supported Versions

Security fixes are applied to the latest stable minor release.

| Version | Supported          |
| ------- | ------------------ |
| 1.3.x   | :white_check_mark: |
| < 1.3   | :x:                |

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately by email to
[bayudwiyansatria@gmail.com](mailto:bayudwiyansatria@gmail.com). Do not open a public GitHub issue.

Include:

- A clear description of the vulnerability and affected versions
- Reproduction steps or a proof of concept
- The potential impact and attack scenario
- Any suggested remediation
- Whether the report may be shared with other maintainers or vendors

You can expect acknowledgment within three business days. The maintainer will investigate, coordinate a fix and release,
and agree on a disclosure timeline with the reporter. Please allow reasonable time for remediation before public
disclosure.

Reports made in good faith to improve the security of this project are welcome. Avoid accessing data that does not
belong to you, disrupting services, or performing tests that affect other users.
